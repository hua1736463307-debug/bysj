# 范围声明：面向多病种的医学影像辅助诊断系统（胸片五标签辅助分析）

> 版本：2026-10-27 / v1.0
> 分支：`graduation/cxr-assist-20261027`　基线：`d22a16d52c6124b803a8af2cd09dd56a58fefb20`
> 依据：`DS医疗辅助诊断改造计划_20261027`（01 实施计划书 / 02 技术契约 / 03 验证与接续）

## 1. 题目与范围

建议题目：**《面向多病种的医学影像辅助诊断系统设计与实现》**。

首期只实现并验证**胸部 X 光（正位）多标签辅助分析**。平台保留 `task_kind` / 标签 / 模型契约的扩展位，但本轮不接入第二种检查类型，也不做 CT/MRI 融合、三维分割、DICOM 解析、HIS/PACS 对接、问诊大模型、处方或治疗推荐。

固定任务标识 `cxr_multilabel`，标签 schema `cxr-five-v1`，顺序不可变更：

| index | 稳定 key | 原始标签列 | 展示名 |
|---|---|---|---|
| 0 | atelectasis | Atelectasis | 肺不张 |
| 1 | cardiomegaly | Cardiomegaly | 心影增大 |
| 2 | consolidation | Consolidation | 肺实变 |
| 3 | edema | Edema | 肺水肿 |
| 4 | pleural_effusion | Pleural Effusion | 胸腔积液 |

这五项是**研究观察结果**（含影像征象），不是五种疾病的确诊结论。系统输出"模型评分 + 阈值 + 是否需复核"，不输出"确诊"。

## 2. 主业务闭环

匿名病例/检查影像 → 输入与模型匹配校验 → 五标签评分 → 关注区域与解释信息 → 医生/研究审核者复核 → 可追溯的辅助报告。

审核者身份与意见必须来自实际操作；不给自动生成内容冒用医生署名，也不自动批准。

## 4. 本轮不做（明确排除）

- 跨科室通用诊断、问诊大模型、处方/治疗推荐
- HIS/PACS 对接、DICOM 解析、CT/MRI 多模态融合、三维分割
- 在线自动学习、临床上线、临床试验
- 训练回流生成新数据版本（P1 之后；本轮只做到审核与报告）
- 第二套后端 / 第二套作业系统 / 第二套 GPU 租约

上传首期支持 8bit JPG/PNG；DICOM、16bit、windowing 明确返回 `unsupported_format`，不套用摄影图归一化。

## 6. 不可越过的红线

1. 不伪造患者、人工意见、模型精度或数据访问。
2. 不用 ImageNet 骨干或随机权重冒充诊断模型；无训练模型时分析端返回 `model_unavailable`。
3. 不把"未超过五项阈值"表述为"已排除所有疾病"或"患者健康"。
4. 热力图只称"模型关注区域"，无定位真值时不报 IoU/Dice，不称病灶定位准确。
5. test 集只在模型、预处理、标签策略、阈值方案冻结后读取一次；读取后改方案必须新协议并披露探索性。
6. 不把公开榜单 AUC、旧 BCCD 指标、他人论文指标当本项目结果。
