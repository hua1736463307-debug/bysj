## 模型

- 架构：`torchvision.models.densenet121(weights=None, num_classes=5)`，ImageNet 骨干仅作初始化来源（`cxr_backbone`）。
- 输出：五路独立 `sigmoid`，**禁止 softmax**；分数不要求和为 1。
- 损失：`sum(mask * BCEWithLogitsLoss(logits, y, reduction='none')) / sum(mask)`；整 batch mask 全 0 → 跳过优化（不除 0）；全程无有效更新 → 失败。
- 对比臂：A0 无类别权重；A1 `pos_weight = clip(Nneg/Npos, 1, 20)`，仅用 train 统计，缺正/负例直接失败。
- 选择：val macro AUROC 最大化，tie 取更早 epoch；全部标签 AUROC 不可定义 → 训练门禁失败。

## 预处理 `cxr-preprocess-v1`

RGB（灰度复制三通道）→ 保比例缩放到短边 224（双线性）→ 居中补 0 到 224×224 → ImageNet mean/std → CHW float32。无随机裁剪/翻转/旋转/mosaic。缩放与填充参数写入 meta，供 Grad-CAM 回映。

**这是与 torchvision 官方 DenseNet 默认中心裁剪不同的独立设计**，已在 `docs/cxr/SCOPE.md` 与模型 metadata 记录差异，不声称已获临床证实。

## 加载安全

- 只接受受控可信 `state_dict`；`torch.load(..., weights_only=True)`。
- 加载前校验 `label_schema`、`arch`、`num_classes`；缺失/错配 → `422 cxr_checkpoint_invalid` / `cxr_checkpoint_mismatch` / `cxr_schema_mismatch`。
- 骨干 `cxr_backbone` 不得直接分析（`422 cxr_backbone_not_analyzable`）；detect 模型 → `422 model_task_mismatch`。
- 模型文件 hash 与登记不一致 → `409 model_tampered`（测试覆盖）。
