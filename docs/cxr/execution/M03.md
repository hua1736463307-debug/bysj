## 关键规则落地

- **来源边界**：`CXR_SOURCES` 显式映射优先，否则 `<CXR_IMPORT_ROOT>/<source_id>`；未配置 → `409 cxr_source_not_configured`；不存在 → `404`。
- **路径安全**：CSV 内绝对路径、盘符、`..` 一律拒绝；复制后再校验 hash，不一致 → `500 cxr_copy_hash_mismatch`。
- **不硬链接**：`shutil.copyfile`，避免源被修改污染数据集。
- **取样规则**：按 `patient_key` 固定 hash 排序取前 N；患者内按规范化路径取首张；不看标签、不看模型分。
- **四集**：`sha256(namespace|split_seed|component_key)` → 累计比例分配；component < 4 直接拒绝；保证四集非空。
- **重复候选**：同 `pixel_sha256`/`sha256` 跨患者 → 并查集合并为一个 component，记录 `duplicate_candidates`，**不删除样本**。
- **四态无损**：`raw_labels_json` 存四态字符串；`annotations_json` 对 CXR 恒为 `[]`（不生成假 BBox）。
- **伪标识**：`patient_key = sha256(namespace:patient:<id>)[:32]`；目标相对路径只含伪标识；原始路径只进 `selection.json`（受控产物，不进 API）。
- **合成数据门禁**：来源带合成标记且未开启 `CXR_ALLOW_SYNTHETIC` → `409 cxr_synthetic_source_rejected`，避免假数据冒充研究结果。
