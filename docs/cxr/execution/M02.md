## schema（`backend/app/schemas/cxr.py`）

- 标签顺序由 `CXR_LABELS` 常量固定，禁止运行时重排。
- 四态 `positive/negative/uncertain/unmentioned`；`1/0/-1/空` 一一映射；`bool` 与 `2` 明确拒绝。
- `mask=1` 仅 positive/negative；`target_vector` 对 mask=0 返回 `None`（不是 0）。
- `build_label_results` 输出五项完整结果；`flag ∈ {above_threshold, below_threshold, borderline, not_available}`，borderline 边界 0.05。
- 旧 `TrainingParams` / BBox 输出未改义。
