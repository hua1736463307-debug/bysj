`/` 默认跳 `/cxr/dashboard`；旧检测页面保留原路径与 deep-link，导航收敛到"历史研究模块"下拉。

## 交互与安全

- 所有请求经唯一 `api/client.js`：token 注入、401 退出、envelope 解包、`requestId` 进错误提示。
- 幂等键由前端 `crypto.randomUUID()` 生成，每个提交动作一枚。
- 界面文案使用医学/研究语言：显示"模型评分""接近阈值""需复核"，不出现"确诊""已排除"；不展示服务器路径与训练内部实现。
- 图片读取走 `/assets/{id}/image`、`/analyses/{id}/image`、`/artifacts/{id}`，均为鉴权 + `no-store`。
- CAS 冲突（409）显示错误并保留用户已填内容，不静默覆盖。
