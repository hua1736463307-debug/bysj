## 生命周期

- 状态同步：`job_service._sync_domain_state` 新增 `cxr_analyze → CxrAnalysisBatch`、`cxr_evaluate → EvaluationRun`；失败/取消/中断写 `error_code/error_detail`，`completed` 不覆盖 handler 已写结果。
- 受控子进程：`domains/cxr/runner.py` 写 `stop.flag` → SIGTERM → 超时 SIGKILL → `wait()` reap；POSIX 下按进程组信号；`--parent-pid` 让孤儿进程自检退出。
- 取消语义：`JobCancelled` 由 runner 抛出，`run_claimed_job` 记 `cancelled`，`finally` 释放 GPU。
- 陈旧 attempt：产物路径带 `attempt`（`.../evaluations/<id>/<attempt>`、`.../explanations/<id>/<attempt>`），旧 attempt 只能写自己的目录。
- 部分失败：批次内一张失败只标该项 `failed`，其余保留 `completed`，批次状态 `partial`。
- 幂等：所有 POST 走 `job_service.create_job`；同键换内容 → `409 idempotency_conflict`（测试覆盖）。
