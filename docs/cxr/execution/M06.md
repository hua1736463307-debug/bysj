## 指标实现（`backend/app/ml/cxr_metrics.py`）

逐标签、只对 `mask=1` 样本：

| 指标 | 实现 | 不可定义时 |

## 校准与阈值

- 逐标签温度缩放：目标为明确标签的无权 BCE；`T ∈ [0.05, 10]`；粗网格 + 黄金分割细化。
- 门禁：每类需 ≥50 有效样本且 ≥5 正 ≥5 负；否则 `T=1`、`status=not_calibrated`、`reason` 写实（`samples<50` / `positives<5` / `negatives<5`）。
- 阈值：在 calibration 集的**校准评分**（未校准则 raw）上，0.05→0.95 步长 0.05 取 Youden J 最大，tie 取更高阈值；两类不足 → `0.5 + default_no_calibration`。
- 产物：`artifact_root/cxr/evaluations/<run>/<attempt>/calibration.json`，含 temperatures/thresholds/sources/status/split hash/model hash/拟合代码 hash，登记为 `ArtifactRecord`（不可变，新校准写新文件）。

决定：**保留 numpy 实现**，不引入 sklearn 运行时依赖（worker 镜像实测无 sklearn，API 镜像按契约不装 ML 依赖），

对照测试：`backend/tests/cxr/test_cxr_metrics_sklearn.py`（无 sklearn 环境整模块 skip，不阻塞普通 CI）。

| 项 | 对照对象 | 容差 | 结果 |

| AUROC（6 组数据，含大量并列评分） | `sklearn.metrics.roc_auc_score` | 1e-12 | 一致 |

### 口径差异（已固定并写入代码 docstring）

1. **average precision 定义**：阶梯积分 `AP = Σ (R_n − R_{n−1}) · P_n`，阈值按相同评分分组，
   等价于 `average_precision_score`。**不是** PR 曲线梯形面积 `auc(recall, precision)`；
   实测同一用例 AP=0.8667 而梯形面积=0.85，二者可高可低，故本项目不提供梯形 PR-AUC，
   避免论文中把两个量混用。
2. **单类处理**：`roc_auc_score` 在只有一类时抛 `ValueError`；本项目返回 `(None, "single_class")`，
   宏平均只对有定义标签求值并报告 `valid_labels`。这是契约"不填 0、不返回 NaN、不伪造宏平均"的要求，
   属**有意差异**而非实现缺陷。全正例时 AP 仍有定义（=1.0），两侧一致。
3. **ECE 分箱边界**：本项目为左闭右开 `[lower, upper)`（末箱含 1.0）；`calibration_curve` 把恰好
   落在内部边界上的评分归入下箱。连续评分下两者逐箱一致；边界命中时归属不同。测试用
   `test_ece_boundary_convention_differs_from_sklearn` 显式锁定该差异。
4. **落库精度**：bin 表与二分类派生指标按 6 位小数存储，对照按 1e-6 容差；ECE/AP/AUROC 本身用未舍入值。
