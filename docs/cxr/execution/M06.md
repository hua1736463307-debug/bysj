## 指标实现（`backend/app/ml/cxr_metrics.py`）

逐标签、只对 `mask=1` 样本：

| 指标 | 实现 | 不可定义时 |
|---|---|---|
| AUROC | 秩和法（Mann-Whitney），含并列平均秩 | `null + single_class / no_masked_samples` |
| AUPRC | 阶梯积分 average precision，并列评分同阈值分组 | `null + no_positive` |
| Brier | `mean((p-y)^2)` | `null + no_masked_samples` |
| ECE | 10 个固定等宽 bins，`|acc-conf| * n/N` | 同上；附完整 bin 表 |
| 二分类 | 冻结阈值下 TP/FP/TN/FN + 敏感度/特异度/PPV/NPV/F1 | 分母为 0 各自 `null`（不是 NaN） |
| 宏平均 | 只对有定义标签平均，报告 `valid_labels` | `null + no_defined_label` |
| 区间 | 以 patient/component 为单位的 bootstrap（1000 次，seed 42） | `null + insufficient_groups` |

**与 02 契约 G 的偏离（已记录）**：契约建议使用 scikit-learn。本机与 API 运行环境未安装 sklearn，而新增依赖需先做 Linux/Py3.12 完整 hash 锁并 `pip check`，本轮无法在该环境验证。故改为**纯 numpy** 实现，语义与 sklearn 对齐，并显式处理 mask（绝不把 -1/空值矩阵塞进多标签 ROC 函数），同时避免给 API 镜像引入新依赖。

## 校准与阈值

- 逐标签温度缩放：目标为明确标签的无权 BCE；`T ∈ [0.05, 10]`；粗网格 + 黄金分割细化。
- 门禁：每类需 ≥50 有效样本且 ≥5 正 ≥5 负；否则 `T=1`、`status=not_calibrated`、`reason` 写实（`samples<50` / `positives<5` / `negatives<5`）。
- 阈值：在 calibration 集的**校准评分**（未校准则 raw）上，0.05→0.95 步长 0.05 取 Youden J 最大，tie 取更高阈值；两类不足 → `0.5 + default_no_calibration`。
- 产物：`artifact_root/cxr/evaluations/<run>/<attempt>/calibration.json`，含 temperatures/thresholds/sources/status/split hash/model hash/拟合代码 hash，登记为 `ArtifactRecord`（不可变，新校准写新文件）。
