## 部署前提

交付包含迁移 `4a6b1222f005`。运行新版本需要先备份现有数据库，执行 Alembic 升级，再同步更新 API、数据处理与推理 worker 和前端。大小写无关用户名唯一索引要求历史用户名不存在仅大小写不同的冲突，迁移失败应先审查冲突记录。

源码基线归档位于本地 `.planning/parity-20261102/baseline.zip`，SHA256 为 `DA9C5E7C347E0E4586CB6E493A56C4C730008F52CDCCCECD30BE84AA9074585A`。回退需要同时考虑源码与数据库版本，尤其是新增角色权限及归档字段的数据。

## 验证边界

- 真实 GPU 训练、真实医学数据精度及临床有效性未验证。dummy/synthetic 结果继续受研究资格门禁约束。
- 多边形可编辑、派生和导出，当前内置检测训练读取外接框。
- 模型上传支持管理员校验的 `.pt` 检测权重，CXR/ISIC 使用各自模型契约。
- 页面经过浏览器交互和截图检查，原系统在线页面的逐像素对照未执行。
- 主 JavaScript 包约 1.32 MB，gzip 约 424 kB，构建保留大 chunk 提示。
- 当前验证针对隔离候选环境，现有运行服务需要完成上述迁移和组件更新后再进行部署验收。
