## 3. 设计说明

- revision 是**会话级**（owner+dataset+source_version+geometry），不是单图级；前端保存时
  必须使用最近一次返回的 revision。这一点在测试中显式覆盖。
- `deleted_ids` 只做审计/tombstone，实际以 `boxes` 全量为准；避免增量合并歧义。
- Polygon 原数据保留只读，不静默转 BBox（本卡只实现 BBox）。
