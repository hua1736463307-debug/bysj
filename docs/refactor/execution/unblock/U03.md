# U03 任务、GPU 租约与恢复

状态：关键并发与真实取消/崩溃/断联门禁通过。候选部署验证，正式镜像复验仍在后续 U08。

## 机制

租约通过 PostgreSQL 原子竞争，generation 单调保留。GPU holder 包含 worker、job、attempt；失联 GPU 不自动交给新计算。独立线程续租 job/GPU 与角色心跳；产物落库前锁定并检查当前 attempt。训练子进程有独立进程组与 Linux 父进程死亡信号，取消先终止再回收；workers=0 避免未受控数据加载孙进程。

`scripts/recover_gpu_lease.py` 默认仅检查。显式 apply 仅接受同一 bysj Compose 项目的 API/owner 容器；核对旧 owner 已停止、PID=0、角色心跳过期、holder/generation/job 未变化，再释放该租约。不会清空全部租约，不停止其他项目容器。恢复原任务使用已有 `/jobs/{id}/resume`，新 attempt 与旧执行隔离。
