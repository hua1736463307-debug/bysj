## 实现

- TrainingParams 白名单、范围、增强及早停映射；seed=0 保留；不支持字段拒绝。真实子进程保存 effective_args、训练秒数、CUDA allocated/reserved 峰值和运行环境。
- 独立评估保存真实 per-class、混淆矩阵、曲线 JSON 与 PNG 受控产物。评估幂等键固定请求内容；重复请求返回原 run/job，变更内容 409。
- 训练注册后中断的恢复路径验证已有模型哈希及完整 training_result，再补实验记录，避免重复注册。无恢复元数据时明确拒绝覆盖。
- 推理计时包含实际领取等待、GPU 等待、模型加载、框架预处理/推理/后处理、落盘及累计完成延迟；CUDA 同步后取值。
- 实验 runner 按完整协议 SHA-256 分目录，独占创建冻结文件，重跑不覆盖。预检固定模型哈希、数据版本、三集资产/标注摘要、代码与锁哈希、参数。formal 要求精确 Git SHA 与两份锁；engineering_smoke 明确独立标记。
- 每 seed 训练后发起独立 test 评估。中断/失败/取消/超时、缺指标或非有限值不能算成功。均值与 n-1 标准差只来自成功 seed；不足量报告 partial。
- benchmark 收集全部结果分页，缺输入拒绝，不静默截断；同一模型句柄内预热，冷模型与热模型分开，预热从统计样本排除。设备全局显存/RSS 未采样处明确 null/reason。
