## 状态契约

- `inspect`：校验 import.zip / source_groups / PREPARATION 摘要，绑定 base-url、run_id、数据集名。
- `import`：POST 前原子写 `submitting_import`；响应后立即保存 `import_job_id`；复跑只 GET。
- 无 job_id 的超时/断网 → `uncertain=true`，拒绝重发并要求先查服务器。
- `freeze`：已有 frozen 且 seed/group_level 一致则复用；否则写 `submitting_freeze` → POST → 保存 job → 只轮询。
- `verify`：全量分页（page_size=200）、重算图像 sha256、逐图标签比较（1e-6）、来源组映射、
  291/37/36、三类覆盖、组/hash 跨集检查、00037/00038 同组同集。
- `prepare-experiments`：仅 verify 通过后生成 E1/E2 配置骨架。

## 测试

`python -m pytest scripts/tests/test_run_grouped_revision.py -q` → **9 passed**

覆盖：正常完成、复跑不重复 POST、不确定提交不重发、frozen 复用/配置冲突、提交一次并记录 job、
包摘要不匹配、目标身份不一致、分页不全、缺失/重复资产、跨组泄漏。

## 限制

- 真实服务器上的“不确定提交”只能人工核对；脚本不自动查询 jobs 列表（避免误配）。
- `prepare-experiments` 只写输出目录，未直接覆盖 `configs/`。
