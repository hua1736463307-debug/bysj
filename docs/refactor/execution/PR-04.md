## 4. 过程中发现并修复的问题

| 问题 | 现象 | 修复 |
|---|---|---|
| 训练期间未续租 | 训练 >120s 被其它 worker 判为 `interrupted` | `JobContext.progress` 同时 `heartbeat` |
| 子进程 PIPE 阻塞 | Ultralytics 进度输出写满 64KB 管道后训练卡住 | stdout/stderr 重定向到 `training.log` |
| 子进程找不到 app | `ModuleNotFoundError: app` | 子进程注入绝对 `PYTHONPATH` |
| 恢复后租约残留 | 被杀 worker 留下 `gpu:0` 租约 | 重启 worker 前清理过期租约（运维动作） |
