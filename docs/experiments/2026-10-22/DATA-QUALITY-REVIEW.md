## 对现有结论的影响

- E1 的三 seed 和 E2 seed42 数值来自真实训练及评估，保留原日志、权重、协议、模型与评估记录；不删除低指标或覆盖历史数据。
- 这些数值的 train/test 独立性存在已发现风险，不再当作已通过独立性验收的泛化结论。E2 首 seed 较低也不能据此裁定切片方案整体有效或无效。
- 已停止 runner，并经 API 取消 E2 seed43（job 01950a5c-2a7a-4739-b7a9-54f318cd00c5）；09:59 PDT 确认 cancelled、没有登记新模型、GPU holder 为空、在途作业为 0。seed44 未执行。
- 在原 E1/E2 协议目录加入独立 `BLOCKED.json`，未修改 `config.frozen.json`。runner 在提交任何训练前检查该标记，包括 `--retry-cancelled` 也不能绕过。
- E4 是已记录硬件/输入下的工程性能测量，不是泛化精度结论；上述风险不抹去其真实计时。E3 人工质量实验仍未进行。

## 修正路径与剩余边界

1. 保留原协议为历史，并公开说明发现时间、旧 test 已被使用的事实。
2. 为所有图提供显式来源组映射，将这对候选保守合为同一 image_cluster；其余图维持独立来源组。不称为 patient 或 slide 级分组，因为缺少该元数据。
3. 新建数据版本再按组划分，验证相似对同组且同集、组/内容/root 隔离与标签不变；新派生 train-only tiles 保持其父版 val/test。
4. 重新生成协议、代码/数据/模型/锁摘要。后续重划分依然是事后开发/敏感性分析，不能称为“从未见过的独立 test”。要形成更强的确认性结论，需要独立来源或在充分审计后新保留的数据集，以及真实人工/导师认可。
5. dHash 是有局限的筛查：无候选不证明无近重复；旋转、裁剪、染色变化及患者归属未覆盖。不调整阈值去迎合结果，也不因合并这一对就宣称全部泄漏已消除。
