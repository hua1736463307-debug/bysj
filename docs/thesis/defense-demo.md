# 8 分钟演示脚本

> 演示只用公开 BCCD 数据与已完成的真实任务记录；未完成的实验不现场编造。

## 0:00–1:00 背景与范围

- 医学图像检测教学平台：导入 → 标注 → 冻结 → 训练 → 评估 → 推理 → 复核 → 再训练。
- 只做 detect；分割/姿态/监控不在范围。

## 1:00–2:00 数据治理

- 展示 `docs/experiments/dataset-card.md`：364 图、4888 框、291/37/36。
- 展示 `manifest.json` 的 `split_manifest_hash` 与 `check_split_integrity.py` 输出。

## 2:00–3:30 标注与版本

- 打开标注页：画框、撤销/重做、保存返回 revision。
- 第二个标签页用旧 revision 保存 → 409，展示“重新载入/另存子版本”。
- 冻结后尝试编辑 → 409。

## 3:30–5:00 训练与模型

- 训练页提交 1 epoch smoke（或展示已完成的真实任务记录）。
- 展示任务事件、`waiting_gpu`、取消。
- 模型页：sha256、血缘（job/version）、下载前校验。

## 5:00–6:30 评估与推理

- val 评估；test 需管理员 + purpose。
- 单图推理 → 预测框/JSON/CSV；刷新后仍可读。

## 6:30–8:00 复核闭环与总结

- 对一张误检图提交 false_positive，管理员审批。
- 导出回流子版本：展示 train 标注变化、val/test hash 不变。
- 总结已完成/未完成项，明确不宣称临床有效性。

## 离线与故障应对

- 预置：数据 manifest、已训练模型、推理结果、任务 ID。
- 网络不可用时跳过在线训练，直接展示历史任务与产物 hash。
- 任何步骤失败，展示真实错误码（409/422/503），不修改数据“让它通过”。
