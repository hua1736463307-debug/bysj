# bysj · 图像训推实验平台

毕业设计的代码筛选基础版本，来源于个人仓库 `hua1736463307-debug/-xtythpt` 的 `main`，基准提交 `aa331df0657ad4ffcf3c105f9ba52b7e159deb2a`。当前题目暂未确定，暂以“面向图像目标检测的标注、训练与推理实验平台”为工作方向，后续可选择合规公开医学图像数据集适配具体任务。

## 当前保留

1. 图像数据导入、管理、标注草稿及 YOLO/YOLOE 辅助标注。
2. 数据增强、训练集组织、类别管理、划分和导出。
3. YOLO/YOLOE 训练、任务状态、日志、取消和恢复相关实现。
4. 模型管理、训练结果和指标展示、单张与批量图片推理。
5. 登录鉴权、数据归属、任务和模型等基础支撑。

前端只保留数据、标注、训练、模型及图片推理入口，使用新的简化导航。训练页面仍保留原有姿态训练组件作为后续可选参考，不代表已经选定跌倒研究方向。

## 本次不纳入毕设范围

现网部署链、服务器运维、摄像头接入与九宫格监控、人脸抓拍、告警中心、外部告警推送、生产 worker 差异快照。由于现有 `backend/yolo_api.py` 是单体入口，其导入依赖中的部分行为、姿态、人脸及告警源模块仍保留；**这些模块暂未从后端 API 注册中剥离，不能把当前版本视为已完全模块化的最小系统**。

未复制公司数据库、数据集、图片视频、模型权重、真实用户、环境文件或训练输出；移除了现网 GPU/模型配置，替换了原始私网地址示例及默认数据库口令。没有继承原仓库历史；代码来源、原始/筛选后哈希与排除清单见 [source-selection.json](../source-selection.json)。原始开源许可保留在 [LICENSE](../../LICENSE)，依赖许可说明保留在前端第三方许可目录。
